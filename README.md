# Rupt

**Rupt** — минимальный интерпретатор простого скриптового языка, написанный на ассемблере (NASM, x64, Windows API). Проект включает готовый `rupt.exe`, установщик с иконками и исходники.

## Возможности языка

- Файлы скриптов: `.rpt` (также поддерживается `.rtp`).
- Каждый файл **должен начинаться** со слова `rupt`.
- Переменные объявляются через `cit`; **имя переменной должно начинаться с `cit`**:
  ```rpt
  rupt
  cit citName = "Alina"
  cit citAge = 21
  cit citSum = 10 + 5 * 2
  print citName
  print citAge
  print citSum
  print "Hello, " + citName
  ```
- Инструкции: `cit <имя> = <выражение>` и `print <выражение>`.
- Выражения: целые числа, строки в `"..."`, ссылки на переменные, `+ - * /`, скобки `()`.
- `+` выполняет сложение чисел или конкатенацию, если один из операндов — строка.

## Установка (без NASM/GoLink/Python)

1. Скачайте `rupt-installer.zip` из репозитория и распакуйте.
2. Запустите `install.bat` (или `install.ps1`).
3. Откройте **новое** окно терминала и выполните:
   ```bat
   rupt ваш_файл.rpt
   ```

Установщик копирует `rupt.exe` в `%LOCALAPPDATA%\Rupt\bin`, добавляет его в пользовательский `PATH`, назначает значок `rupt.ico` и ассоциации для `.rpt`/`.rtp`. Удаление — `uninstall.bat`.

> Если значки в Проводнике не обновились, нажмите F5 или перезапустите Проводник.

## Быстрый пример

`test.rtp` / любой `.rpt`:
```rpt
rupt
cit citCough = "Kha-kha! *cough* Khe-khe..."
print citCough
print 44
```

Запуск:
```bat
cd C:\Users\lugov\Videos\aline
rupt test.rtp
```

## Сборка из исходников

Исходник интерпретатора: `rupt/rupt.asm`.

Требуются:
- [NASM](https://www.nasm.us/)
- [GoLink](https://www.godevtool.com/)

```bat
cd rupt
build.bat
```
(пути к `nasm.exe`/`GoLink.exe` заданы в `rupt/build.bat`; при необходимости измените их под свою систему.)

Ручная сборка:
```bat
nasm -f win64 rupt.asm -o rupt.obj
GoLink /console /entry main rupt.obj kernel32.dll
```

## Структура репозитория

- `rupt/` — исходники и сборка (`rupt.asm`, `build.bat`, `rupt.exe`, иконки, примеры).
- `rupt-dist/` — содержимое установщика (готовый `bin/rupt.exe`, иконки, скрипты установки, примеры).
- `rupt-installer.zip` — готовый архив установщика.
- `test.rtp` — пример скрипта.

## Ограничения

Текущая версия — минимальная реализация подмножества языка (целые числа, строки, базовые выражения, переменные `cit*`, `print`). Для корректного отображения кириллицы в консоли Windows может потребоваться `chcp 65001`.
